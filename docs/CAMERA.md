# Камера RoboLab

Подключение к агенту и запуск сценария обходятся без захвата кадров. В клиенте откройте **Камера**, выберите вид, частоту и качество JPEG, затем нажмите **Начать просмотр**. Остановка и закрытие окна завершают передачу. Если запросы кадров прекращаются, агент закрывает сеанс через пять секунд.

| Вид | Что отображается |
| --- | --- |
| Исходное изображение | Кадр камеры, при необходимости уменьшенный до 640 × 480 с сохранением пропорций. |
| Оттенки серого | Кадр, преобразованный OpenCV в градации серого. |
| Маска | Границы Canny после сглаживания. |
| Разметка | Исходный кадр с найденными контурами и координатами центра крупнейшего контура в пикселях. |

Можно выбрать от 1 до 8 кадров в секунду и качество JPEG от 35 до 90. Для изменения настроек остановите просмотр и запустите его с новыми значениями. Клиент показывает частоту поступления кадров и возраст JPEG на агенте. Это программные метрики передачи. Кнопка **Сохранить JPEG** сохраняет последний отображённый кадр через окно сохранения платформы или загрузку браузера.

## Проверка на ПК

Установите дополнительные зависимости в окружение агента и включите тестовый источник. Токен и клиент настраиваются по [README](../README.md).

```sh
python -m pip install ".[agent,camera]"
robolab-agent --mock-camera
```

Источник изображает движущуюся сцену и использует тот же OpenCV для обработки и JPEG. Запуски Mock Robot и просмотр тестового источника могут работать одновременно.

## Подключение на Raspberry Pi

Укажите `camera_device` в локальной [конфигурации Yahboom](YAHBOOM.md). Адаптер открывает заданный `/dev/videoN` через V4L2. Используйте OpenCV и NumPy, доступные интерпретатору из поля `python`, включая вызов с `-I`. У пользователя службы должны быть права на видеоустройство.

При просмотре агент удерживает тот же `flock`, что и аппаратный сценарий. Освободите устройство перед просмотром или запуском аппаратного сценария. Учебные программы могут работать с камерой самостоятельно при выключенном просмотре RoboLab. Для вывода промежуточных кадров самих учебных программ понадобится отдельный интерфейс передачи кадров. Текущая маска и контуры строятся в процессе просмотра.

- [Документация Flet FilePicker](https://flet.dev/docs/services/filepicker/)
