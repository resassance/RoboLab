# Телеметрия и эксперименты

Откройте **Телеметрия** после подключения. На Linux агент считывает загрузку CPU, объём RAM, температуру первого термодатчика и состояние и суммарные счётчики сетевых интерфейсов. Первый отсчёт CPU используется как начальная точка. Для платформы или устройства без нужного источника клиент отображает отсутствие значения. Доступность камеры означает, что источник настроен. Статус занятости оборудования относится к запускам и просмотру внутри RoboLab.

В **Экспериментах** можно открыть параметры, статус и длительность запуска, записи журнала и график метрик, выбрать два запуска для сравнения и скачать JSON или CSV. CSV содержит строки разных типов для параметров, журнала и отсчётов. JSON сохраняет структуру записи целиком.

## Метрики алгоритмов

Печатайте в stdout JSON по одному объекту на строку. Ключи в `metrics` задают названия рядов. Значения должны быть конечными числами. Mock Robot выводит `step` и `progress_percent` во время симуляции.

```json
{"event":"reading","message":"Замер завершён","metrics":{"distance_cm":34.2,"confidence":0.91}}
```

Агент хранит последние значения до 32 метрик, до 1000 отсчётов и до 300 строк журнала на запуск. Начало записывается сразу, итоговая запись содержит доступный журнал и отсчёты. При аварийном завершении агента незаконченная запись помечается прерванной после перезапуска. Журнал и отсчёты такого запуска могут отсутствовать.

## Хранение на Raspberry Pi

По умолчанию `robolab-agent` сохраняет `history.sqlite3` в каталоге `~/.robolab/data`. На Pi с OverlayFS задайте каталог на постоянном томе с правом записи для пользователя агента. Один каталог относится к одному агенту.

```sh
robolab-agent --data-dir /var/lib/robolab/experiments --yahboom-config /etc/robolab/yahboom.local.json
```
